# Bloobs-Idle-Auto-Challenge-Tracker
Mod for Bloobs Adventure Idle to remove the micromanaging from challenges.

IMPORTANT: Mods are not officially supported. Do not report issues caused by the mod to the developer.

* Automatically track challenges when you perform the related activity. 
* Increases max challenges tracked (basically just for the tracker visual) and auto-progresses the tier. 
* Challenges move to the top of the tracker when they are progressed.


Install using BepinEx; use at your own risk.
